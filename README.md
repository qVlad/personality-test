# test1

Веб-приложение для анкетирования, которое позволяет классифицировать человека и определить его тип личности.

## Описание

Сервис предоставляет пользователям возможность пройти анкетирование и получить результат классификации по типу личности.

## Технологический стек

- **Frontend**: React
- **Backend**: Node.js
- **Язык**: TypeScript/JavaScript

## Начало работы

### Требования

- Node.js 18+
- npm или yarn

### Установка

```bash
# Клонировать репозиторий
git clone <repository-url>
cd test1

# Установить зависимости
npm install

# Запустить в режиме разработки
npm run dev
```

## Структура проекта

Проект использует [Specify Spec Kit](https://github.com/anthropics/specify) для управления спецификациями и планирования.
